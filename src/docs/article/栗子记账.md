## 一、为什么做栗子记账

记账是一件非常私人的事——**数据应该只属于自己**。栗子记账围绕这个理念设计：

- **无广告、无推送、无账号体系**，装上即用，记完即走
- **账目数据 100% 保存在手机本地**（SQLite 数据库），不经过任何服务器
- 只有在主动使用"记账定位"时，才会调用地图服务获取地名，且只保存你确认的位置
- 支持随时把完整数据库导出为文件，换手机、备份都由自己掌控

## 三、功能介绍

### 快速记账

![记一笔主界面：金额、分类与数字键盘|280](/img/chestnut/add-bill.jpg)

- 支出 / 收入一键切换，自定义数字键盘，输入金额即点即记
- 支持小数金额、小数点两位约束、超长金额自动缩小防溢出
- "再记一笔"模式：保存后保留分类与日期，连续记账不打断
- 每笔账单可备注、可修改、可复制、可删除
- 日期时间自由选择：今天 / 昨天 / 前天快捷入口，循环滚轮选日，Material 钟面选时间

### 优惠记录

![记一笔优惠输入|280](/img/chestnut/discount.jpg)

- 点"优惠"胶囊切换模式，输入优惠金额（如满减、折扣），实付金额自动计算
- 列表与详情页显示"省 ¥x"绿色标签，实付为 0 时显示"免单"二字
- 统计与预算一律按实付金额计算，优惠金额单独汇总展示
- 免单账单详情页显示"原价 ¥x 划线 · 省 ¥y"，优惠来源一目了然

### 两级分类，自由管理

![分类管理与图标选择|280](/img/chestnut/categories.jpg)

- 一级分类 + 二级分类分组展开选择，层级清晰、单手可达
- 内置餐饮、交通、购物、住房、日常、娱乐、医疗、教育等常用分类及子类，开箱即用
- 15 组内置图标库（数百个 Material 图标）+ 9 色分类色板
- 没有合适图标？分类默认支持**文字图标**（自动取名称首字），零额外成本
- 支持新增 / 编辑 / 删除分类、一级二级互转、跨组移动
- 长按拖拽排序，批量点选图标一次添加多个分类

### 统计分析

![分类占比饼图与同比柱状图|280](/img/chestnut/stats.jpg)

- 饼图展示各支出分类占比，小占比分类也不遗漏：引导线 + "名称 百分比"标签自动避让
- 饼图支持手指拖动旋转，标签同步跟随
- 月度 / 年度 / 全部时间维度自由切换，环心显示收支合计
- 月度柱状图带**去年同期对比**标注，一眼看出同比变化
- 支持关键词搜索 + 自定义起止日期组合筛选
- 分类树多选筛选：一级展开选二级，跨组多选，点一级全选整组

### 标签

![标签管理：拖动排序与编辑|280](/img/chestnut/tags.jpg)

- 账单可打多个标签（如"工作餐"、"聚餐"、"出差"），比分类更灵活
- 记一笔时点 # 快速选标签，已选标签显示在金额下方
- 标签管理页：单击编辑名称与颜色、删除前提示影响账单数、**长按拖动排序**
- 统计页支持按标签筛选，可与分类、日期、关键词组合使用
- CSV 导出含标签列，数据迁移不丢失

### 预算管理

![月度总预算与分类预算|280](/img/chestnut/budget.jpg)

- 月度**总预算**与**一级分类预算**分开设置，互不冲突
- 记账后自动检查用量：达到 80% 提醒控制开销，超支提示超出金额（同级别只提醒一次，不骚扰）
- 总预算卡显示日均可用金额（按本月剩余天数计算）
- 未设置预算的月份可一键沿用上月预算

### 记账定位（特色功能）

"钱花在哪儿"本应是记账的天然维度，但多数记账软件只记录金额与分类。栗子记账把**完整的地图选点能力**做进了记账流程——不是简单附一个城市标签，而是每一笔都能精确到具体的店：

![地图选点：上半屏地图、下半屏附近地点列表|280](/img/chestnut/location-picker.jpg)

- 记一笔时可附带消费地点，账单列表与详情中显示位置小字
- 上半屏地图中心固定大头针，**拖动地图即可选择任意位置**，不限于当前定位
- 下半屏附近地点列表：周边店铺 / 楼宇按距离排序，首项为针所在位置的结构化地址（省市区街道）
- 搜索框支持地点输入提示，搜小区 / 写字楼 / 店铺就近优先；**异地补记**时搜城市名可直接飞到当地再选点
- 坐标与完整地址（行政区划 + 店名）一起保存；编辑旧账单时地图直接回到老地点，红色图钉标记并提供"回到这里"入口
- GPS 坐标自动转换为国内地图坐标系，避免几百米偏移
- 定位功能默认关闭，在"我的"页手动开启；不授予定位权限完全不影响记账
- 定位失败 / 超时 / 无权限均有明确提示与重试入口

### 账单导入

![钱迹导入：分类映射与导入预览|280](/img/chestnut/import.jpg)

- 支持从**钱迹** App 导出的 xlsx 文件一键导入历史账单
- 分类自动映射（钱迹分类 → 栗子记账分类），未匹配的自动创建对应分类
- 导入前自动留底当前数据库，导入结果页显示成功 / 失败 / 跳过的笔数
- 支持整批撤销：误导入可一键回滚到导入前状态
- 标签列自动解析，账单备注、时间、金额完整保留

### 数据备份与恢复

![备份与恢复页面|280](/img/chestnut/backup.jpg)

账目数据是核心资产，备份机制做得比较重：

- **手动导出**：一键生成完整数据库快照（`.sqlite` 文件），可通过微信等分享，或"保存到手机"
- **手动导入**：选择备份文件后先做完整性预检，强确认后覆盖恢复，恢复前自动留底当前数据
- **自动备份**：App 版本升级前、降级前自动备份旧数据库，无需用户操心
- 所有备份均为标准 SQLite 文件，不绑定任何账号

## 四、技术实现

栗子记账使用 Flutter 开发，一份代码维护 Android 端：

| 方面 | 选型 |
|------|------|
| 框架 | Flutter（Material 3 风格，全中文本地化） |
| 本地数据库 | drift（SQLite 类型安全 ORM），响应式 Stream 驱动 UI |
| 状态管理 | Provider |
| 地图定位 | 高德地图 SDK + Web 服务（GCJ-02 坐标） |
| 数据持久化 | SQLite + SharedPreferences（配置项） |

工程上的一些细节：

- 数据库版本从干净的 v1 基线起步，结构变更走增量迁移，迁移前自动 VACUUM 备份
- 金额全部以**分**为单位存整数，从根上杜绝浮点精度问题
- 分类图标码点存数据库、运行时动态渲染，发布构建关闭图标树摇（`--no-tree-shake-icons`）
- release 包开启 R8 混淆与资源收缩，仅打包 arm64 架构，体积约 58MB
- debug / release 使用同一签名证书，地图 Key 指纹无需区分环境

## 五、隐私说明

- 不申请手机号、不注册、不登录，不收集任何个人身份信息
- 账目、备注、位置等全部数据仅保存在本机应用私有目录
- 定位功能为**按需触发**：仅在你主动点击定位 / 打开地图选点时，向地图服务请求当前位置周边与地点搜索结果；不后台上报位置
- App 不含统计 SDK、广告 SDK（地图服务自身的网络请求遵循其隐私政策）
- 卸载 App 即删除全部本地数据，卸载前请先用导出功能备份
