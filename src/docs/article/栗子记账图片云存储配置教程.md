栗子记账 v1.2 起支持**账单图片凭证**：给每笔账单附上小票、发票的照片，随手记、随时查。

图片默认保存在手机本地。如果你希望换手机、清缓存后凭证不丢，可以把图片上传到**你自己配置的云存储空间**——栗子记账只负责直传，**不经手、不中转、不备份**，开发者与任何第三方服务器都无法接触你的图片。

> 未配置云存储时，图片功能依然可用：图片只存在手机本地，功能与之前完全一致，不强制任何网络配置。

## 一、为什么要自己配置

- **数据主权**：图片存在你自己的存储桶里，桶是你的、密钥是你的，想删想搬随时可以
- **成本可控**：推荐 Cloudflare R2，每月免费额度 10GB 存储，且**没有下载流量费**。图片上传前会自动压缩（长边 1800、JPEG 品质 80），单张约 200~400KB，一年记几百张小票也用不完免费额度
- **无锁定**：任何 S3 兼容存储都能用（阿里云 OSS、腾讯云 COS、自建 MinIO 等），填对应的 Endpoint 即可

## 二、开通 Cloudflare R2（约 10 分钟）

### 1. 注册并开通 R2

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) 注册账号（免费计划即可，无需绑定信用卡也能使用 R2 免费额度）
2. 左侧菜单进入 **R2 对象存储**，首次使用按提示开通（会提示查看并同意条款）

### 2. 创建存储桶

1. R2 页面点击 **创建存储桶**
2. 桶名随意（例如 `my-notes`），位置选择 **亚太地区（APAC）** 即可
3. 其余选项保持默认，点击创建

### 3. 创建访问密钥

1. 在 R2 概览页右上角点击 **管理 R2 API 令牌** 如下图：
   ![管理 R2 API 令牌](/img/chestnut/createR2apikey.png)
2. 点击 **创建 API 令牌**，权限选择 **对象读和写（Object Read & Write）**
3. 指定存储桶范围选 **仅应用到特定存储桶**，勾选你刚创建的桶（最小权限原则，这个密钥只能动这一个桶）
4. 创建成功后会显示两组信息，**立即复制保存**（Secret 只显示一次）：
   - **访问密钥 ID**（Access Key ID）
   - **机密访问密钥**（Secret Access Key）

### 4. 拿到 Endpoint

1. 进入你的存储桶概览页
2. 找到 **S3 API** 字样后面显示的地址，形如：
   `https://<账户ID>.r2.cloudflarestorage.com`
3. 复制这个地址（这就是 App 里要填的 Endpoint，**不带桶名后缀**）

## 三、App 内配置

打开栗子记账 → **我的** → **图片云存储**，依次填写：

| 字段 | 填什么 |
| --- | --- |
| Endpoint | `https://<账户ID>.r2.cloudflarestorage.com` |
| 桶名（Bucket） | 你创建的桶名，如 `my-notes` |
| Access Key ID | 第二步拿到的访问密钥 ID |
| Secret Access Key | 第二步拿到的机密访问密钥 |
| 区域（可选） | R2 留空或填 `auto` 即可，其他服务商按控制台填写 |

填好后点击 **测试连接**：App 会真实上传一个测试文件再删除（`chestnut/connection-test.txt`），绿色"连接成功"提示出现后，打开 **启用图片云存储** 开关，配置完成。

> 每次修改 Endpoint、桶名或密钥后，需要重新测试连接才会放行启用开关。

## 四、怎么用

- **记一笔**：金额行上方的胶囊行里点 **图片** → 拍照或从相册选择（可多张）→ 保存账单时自动压缩并上传，胶囊显示 `图片(N)` 计数
- **列表**：挂有图片的账单，分类图标右下角有一个小相机角标
- **详情**：点开账单详情，金额下方是缩略图条，点击可全屏放大查看
- **补传**：断网时上传失败不用管，下次打开 App 会静默重传；详情页图片右上角的橙色感叹号也可以点击立即重传
- **删除**：删除账单时，本地图片与云端副本会一并删除

## 五、常见问题

**测试连接提示"签名校验失败（HTTP 403）"**
Access Key ID 或 Secret Access Key 填错了。Secret 只在创建时显示一次，如果丢了就重新创建一个 API 令牌。

**提示"路径不存在（HTTP 404）"**
检查两点：Endpoint 是否复制的 **S3 API** 地址（不是桶的公开访问网址）；桶名拼写是否一致。

**提示"该存储不支持操作（HTTP 405）"**
所填的服务不是 S3 兼容存储，或 Endpoint 填成了网页控制台地址。

**上传一直失败**
检查手机网络；如果用了防火墙/广告拦截类工具，放行你的 Endpoint 域名。失败的图片会在下次启动 App 时自动补传。

**桶里怎么有个 connection-test.txt？**
那是"测试连接"留下的测试文件，删除失败不影响使用，可在 Cloudflare 控制台手动删掉。你的账单图片都在 `chestnut/receipts/` 目录下，按账单 ID 分文件夹存放。

**隐私说明**
图片仅在你主动添加时上传至你本人配置的存储空间，栗子记账不经手、不中转、不备份。详见[隐私政策](/docs/article/栗子记账隐私政策.html)。
