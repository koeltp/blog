## 一、列表：Python 最灵活的数据结构

### 1.1 创建与访问

```python
# 创建列表
fruits = ["苹果", "香蕉", "橙子"]
mixed = [1, "hello", True, None, [1, 2, 3]]  # 可以混类型（但不推荐）
empty = []
empty2 = list()

# 索引访问
print(fruits[0])   # 苹果
print(fruits[-1])  # 橙子（倒数第一个）

# 切片
print(fruits[1:])    # ['香蕉', '橙子']
print(fruits[:-1])   # ['苹果', '香蕉']
print(fruits[::2])   # ['苹果', '橙子']

# 列表是可变的
fruits.append("葡萄")
fruits[0] = "西瓜"
print(fruits)  # ['西瓜', '香蕉', '橙子', '葡萄']
```

### 1.2 常用方法

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]

# 增
nums.append(10)       # 末尾添加
nums.insert(0, 0)     # 指定位置插入
nums.extend([7, 8])   # 合并列表（等价于 nums += [7, 8]）

# 删
removed = nums.pop()      # 弹出末尾元素
removed = nums.pop(2)     # 弹出索引 2 的元素
nums.remove(1)            # 删除第一个值为 1 的元素
# nums.clear()            # 清空列表

# 查
print(nums.index(5))      # 返回索引
print(nums.count(1))      # 返回出现次数
print(5 in nums)          # True

# 改
nums[0] = 99

# 排序
nums.sort()               # 原地排序（升序）
nums.sort(reverse=True)   # 降序
nums.sort(key=len)        # 按长度排序
sorted_nums = sorted(nums)  # 返回新列表，不修改原列表

# 反转
nums.reverse()
reversed_nums = list(reversed(nums))
```

### 1.3 浅拷贝 vs 深拷贝

```python
import copy

original = [1, 2, [3, 4]]

# 浅拷贝：只拷贝第一层
shallow = original.copy()
shallow[2].append(5)
print(original)  # [1, 2, [3, 4, 5]]  ← 嵌套列表也被改了！

# 深拷贝：递归拷贝所有层级
deep = copy.deepcopy(original)
deep[2].append(6)
print(original)  # [1, 2, [3, 4, 5]]  ← 不受影响
```

## 二、元组：不可变的列表

### 2.1 创建与特点

```python
# 创建元组
point = (3, 4)
empty = ()
single = (42,)  # 注意逗号！(42) 只是整数 42

# 元组是不可变的
# point[0] = 5  # ✗ TypeError

# 但元组可以包含可变对象
container = ([1, 2], [3, 4])
container[0].append(3)  # ✓ 可以修改列表内容

# 元组的优势：更快、内存更小、可用作字典的键
coord = (39.9, 116.4)  # 北京的经纬度
```

### 2.2 元组解包

```python
# 基本解包
x, y = (3, 4)
print(f"x={x}, y={y}")  # x=3, y=4

# 交换变量（不需要临时变量）
a, b = b, a

# 收集剩余元素
first, *rest = [1, 2, 3, 4, 5]
print(first)  # 1
print(rest)   # [2, 3, 4, 5]

# 忽略不需要的值
_, age, _ = ("Alice", 25, "北京")
print(age)  # 25

# 嵌套解包
person = ("Alice", (25, 170), ["Python", "JavaScript"])
name, (height, weight), hobbies = person
```

> **为什么需要元组？**
> - 返回多个值时：`return name, age, city` 实际上返回一个元组
> - 作为字典的键：`(lat, lon)` 可以作为地理位置的键
> - 不可变保证数据安全

## 三、列表推导式进阶

### 3.1 基本形式回顾

```python
# [表达式 for 变量 in 可迭代对象]
squares = [x**2 for x in range(10)]
evens = [x for x in range(20) if x % 2 == 0]

# 条件表达式
labels = ["偶数" if x % 2 == 0 else "奇数" for x in range(6)]
```

### 3.2 嵌套推导式

```python
# 二维矩阵转置
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
transposed = [[row[i] for row in matrix] for i in range(3)]
print(transposed)  # [[1, 4, 7], [2, 5, 8], [3, 6, 9]]

# 展平嵌套列表
nested = [[1, 2], [3, 4, 5], [6]]
flat = [x for sublist in nested for x in sublist]
print(flat)  # [1, 2, 3, 4, 5, 6]
```

### 3.3 字典和集合推导式

```python
# 字典推导式
word = "hello"
char_counts = {c: word.count(c) for c in word}
print(char_counts)  # {'h': 1, 'e': 1, 'l': 2, 'o': 1}

# 集合推导式（去重）
numbers = [1, 2, 2, 3, 3, 4]
unique_squares = {x**2 for x in numbers}
print(unique_squares)  # {1, 4, 9, 16}
```

## 四、列表 vs 元组：如何选择

| 特性 | 列表 `[]` | 元组 `()` |
|------|----------|----------|
| 可变性 | 可变 | 不可变 |
| 性能 | 较慢 | 较快 |
| 内存 | 较大 | 较小 |
| 哈希 | 不可哈希（不能作字典键） | 元素都可哈希时可作键 |
| 语义 | 同类数据的集合 | 异类数据的记录 |
| 典型用途 | 动态列表、队列 | 坐标、数据库记录、函数返回值 |

> **经验法则**：如果数据结构是"同类元素的集合"（如一组用户 ID），用列表；如果是"异类字段的记录"（如一个用户的 name、age、email），用元组。

## 五、AI/LLM 场景中的列表与元组

### 5.1 处理消息历史

```python
# Chat API 的消息列表
messages = [
    {"role": "system", "content": "你是一个有用的助手。"},
    {"role": "user", "content": "Python 是什么？"},
    {"role": "assistant", "content": "Python 是一门编程语言。"},
]

# 追加新消息
messages.append({"role": "user", "content": "请举例说明。"})

# 限制上下文长度（保留最近 N 条消息）
MAX_MESSAGES = 10
messages = messages[-MAX_MESSAGES:]

# 提取所有用户消息
user_messages = [msg["content"] for msg in messages if msg["role"] == "user"]
```

### 5.2 批量处理 token

```python
# 模拟 LLM 返回的 token IDs
token_ids = [1234, 5678, 9012, 3456, 7890]

# 批量分块处理（chunk size = 3）
chunk_size = 3
chunks = [token_ids[i:i+chunk_size] for i in range(0, len(token_ids), chunk_size)]
print(chunks)  # [[1234, 5678, 9012], [3456, 7890]]

# 统计 token 总数
total_tokens = sum(1 for _ in token_ids)
```

## 六、本章小结

| 概念 | 核心要点 |
|------|---------|
| 列表创建 | `[]` 或 `list()` |
| 列表方法 | append/pop/insert/remove/sort/reverse/index/count |
| 切片 | `[start:stop:step]`，返回新列表 |
| 元组 | `()`，不可变，支持解包 |
| 解包 | `a, b = (1, 2)`，`*rest` 收集剩余 |
| 推导式 | `[expr for x in iter if cond]`，一行替代循环 |
| 浅拷贝 | `.copy()`，嵌套对象共享引用 |
