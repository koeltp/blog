## 一、文件读写

### 1.1 基本读写

```python
# 写入文件
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("你好，世界！\n")
    f.write("这是第二行。\n")

# 读取整个文件
with open("hello.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# 逐行读取
with open("hello.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())  # strip 去掉行尾换行符

# 读取所有行为列表
with open("hello.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print(lines)  # ['你好，世界！\n', '这是第二行。\n']
```

> **为什么用 `with`？** `with` 语句确保文件在使用完毕后自动关闭，即使发生异常也不会泄漏资源。这是 Python 的最佳实践。

### 1.2 打开模式

| 模式 | 含义 | 文件不存在 |
|------|------|-----------|
| `"r"` | 只读（默认） | 报错 |
| `"w"` | 只写（覆盖） | 创建新文件 |
| `"a"` | 追加 | 创建新文件 |
| `"r+"` | 读写 | 报错 |
| `"wb"` | 二进制写入 | 创建新文件 |
| `"rb"` | 二进制读取 | 报错 |

```python
# 追加模式
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("[INFO] 程序启动\n")
    f.write("[ERROR] 连接失败\n")

# 读取追加的内容
with open("log.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

### 1.3 大文件处理

```python
# 大文件不要一次性 read()，逐行读取
with open("large_file.txt", "r", encoding="utf-8") as f:
    for line in f:
        process(line)  # 处理每一行

# 或者分批读取
CHUNK_SIZE = 8192
with open("large_file.txt", "r", encoding="utf-8") as f:
    while chunk := f.read(CHUNK_SIZE):  # 海象运算符（Python 3.8+）
        process(chunk)
```

## 二、异常处理

### 2.1 基本结构

```python
try:
    # 可能出错的代码
    number = int(input("请输入一个数字："))
    result = 100 / number
    print(f"结果是：{result}")
except ValueError:
    # 处理值错误（输入的不是数字）
    print("输入无效，请输入一个数字！")
except ZeroDivisionError:
    # 处理除以零
    print("不能除以零！")
except (TypeError, IndexError) as e:
    # 同时处理多种异常
    print(f"发生错误：{e}")
except Exception as e:
    # 捕获所有其他异常（兜底）
    print(f"未知错误：{e}")
else:
    # 没有异常时执行
    print("计算成功！")
finally:
    # 无论是否异常都执行
    print("程序结束")
```

### 2.2 异常层次结构

```
BaseException
 ├── KeyboardInterrupt
 ├── SystemExit
 └── Exception          ← 我们通常只捕获这个及其子类
      ├── ValueError
      ├── TypeError
      ├── KeyError
      ├── IndexError
      ├── FileNotFoundError
      ├── IOError
      ├── ConnectionError
      └── ...
```

> **原则**：捕获具体的异常类型，不要盲目捕获 `Exception`。知道什么会出错，就只捕获什么。

### 2.3 抛出异常

```python
# 手动抛出
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError(f"年龄必须在 0-150 之间，收到：{age}")
    return age

# 重新抛出
try:
    result = 1 / 0
except ZeroDivisionError:
    print("捕获到除零错误")
    raise  # 重新抛出，让上层处理

# 链式异常
try:
    int("not_a_number")
except ValueError as e:
    raise RuntimeError("解析用户输入失败") from e
```

## 三、自定义异常

```python
class APIError(Exception):
    """API 调用失败的基类"""
    def __init__(self, message, status_code=None):
        super().__init__(message)
        self.status_code = status_code

class RateLimitError(APIError):
    """速率限制错误"""
    def __init__(self, retry_after=60):
        super().__init__(f"请求过于频繁，请在 {retry_after} 秒后重试", status_code=429)
        self.retry_after = retry_after

# 使用
raise RateLimitError(retry_after=120)
```

### 4.2 自定义上下文管理器

```python
import contextlib

# 方式一：类
class Timer:
    """计时器上下文管理器"""
    def __init__(self):
        import time
        self.start_time = None
        self.end_time = None
    
    def __enter__(self):
        import time
        self.start_time = time.perf_counter()
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        self.end_time = time.perf_counter()
        elapsed = self.end_time - self.start_time
        print(f"耗时：{elapsed:.4f} 秒")
        return False  # False = 不吞掉异常

# 使用
with Timer():
    import time
    time.sleep(1)
# 输出：耗时：1.0012 秒

# 方式二：装饰器（更简洁）
@contextlib.contextmanager
def timer():
    """计时器生成器"""
    import time
    start = time.perf_counter()
    try:
        yield
    finally:
        end = time.perf_counter()
        print(f"耗时：{end - start:.4f} 秒")

with timer():
    import time
    time.sleep(0.5)
```

## 五、日志记录

### 5.1 logging 模块

```python
import logging

# 配置日志
logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    handlers=[
        logging.FileHandler("app.log", encoding="utf-8"),
        logging.StreamHandler()  # 同时输出到控制台
    ]
)

logger = logging.getLogger(__name__)

# 不同级别
logger.debug("调试信息：请求参数=%s", {"model": "gpt-4"})
logger.info("程序启动")
logger.warning("API 响应时间超过 5 秒")
logger.error("连接数据库失败", exc_info=True)  # exc_info=True 包含堆栈跟踪
logger.critical("系统崩溃，无法恢复")
```

### 5.2 日志级别

| 级别 | 数值 | 用途 |
|------|------|------|
| DEBUG | 10 | 详细调试信息 |
| INFO | 20 | 一般信息 |
| WARNING | 30 | 警告（仍可运行） |
| ERROR | 40 | 错误（部分功能失败） |
| CRITICAL | 50 | 严重错误（程序无法继续） |

### 6.3 带重试的 API 调用

```python
import time
import logging

logger = logging.getLogger(__name__)

def call_with_retry(func, max_retries=3, delay=1, backoff=2):
    """带指数退避重试的 API 调用"""
    for attempt in range(1, max_retries + 1):
        try:
            return func()
        except (ConnectionError, TimeoutError) as e:
            logger.warning(f"第 {attempt}/{max_retries} 次尝试失败：{e}")
            if attempt == max_retries:
                logger.error("达到最大重试次数，放弃")
                raise
            wait_time = delay * (backoff ** (attempt - 1))
            logger.info(f"等待 {wait_time} 秒后重试...")
            time.sleep(wait_time)

# 使用
try:
    call_with_retry(lambda: make_api_call("你好"))
except Exception as e:
    logger.error(f"API 调用最终失败：{e}")
```
